In short:

- In the schematic editor, the name you give a symbol is drawn inside its shape (gates, multiplexers, flip-flops and
  the others); a name too long for it stays above it.

In detail:

- **The instance name inside the symbol (#2036):** at its body's centre (a triangle's: nearer its wide side), turned
  symbols too, when it fits the body's width; else above the symbol as before.
